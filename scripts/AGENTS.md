# 本机脚本约定

本文件约束本目录；修改根目录 `start.ps1` 时也读取，因为它与 `launcher-*.ps1` 共同管理启动生命周期。

- 从仓库路径解析依赖与工作目录，支持在其他目录以绝对路径调用。API 与 worker 共享数据目录，前端代理指向本次启动的 API。
- 生产模式先构建再启动，构建失败不得继续；开发模式按明确选项启动。端口占用时退出，不终止已有用户进程。
- Windows Job Object 与包装器只拥有本次启动的进程树；停止、Ctrl+C 或子进程失败时清理自己的服务，不按进程名称批量结束其他实例。
- 不为启动修改持久系统执行策略。日志与验收产物放在 `.cache/` 或显式隔离路径，不写入源码目录或包含密钥。
- `verify_*.py` 通过实际 API/worker 入口验证行为，运行前满足各脚本隔离条件；禁止去掉保护以直接操作用户数据库。
- `fixture_api.py` 和模拟服务只用于验收，不能成为生产入口或掩盖真实上游故障。

启动器变更验证端口冲突、构建失败、正常启动、Ctrl+C、异常退出与进程树清理。涉及 PowerShell 宿主差异时分别记录实测版本。验收脚本变更检查成功及失败后的资源清理；入口见 [README](../README.md)。
