# 文献业务

`retrieval.py` 提供项目文献与 OpenAlex 检索、排名合并、收藏夹候选及跨查询候选排序；`evidence.py` 提供论文及网页证据提取。业务函数使用普通参数，不依赖 LangGraph。可调用工具入口见 [src/tools](../tools/README.md)，单图八节点的规划、有限补检、分析与终稿生成见 [Agent 工作流](../agents/README.md)。

检索保留单次研究运行的跨轮候选池，论文按 DOI、arXiv ID、本地 ID 等身份标识去重，网页按去掉 fragment 的 URL 去重；不同查询的排名使用 RRF 合并，同一查询不重复增加权重。RRF 只合并检索排序，不是语义重排。收藏夹检索返回提交时的完整论文快照与当前项目的交集，不能扩展到外部来源。候选池按来源分开保存；研究节点每次取证调用最多选择六条候选，不在候选入池前截断。

网页候选来自配置的搜索引擎；公网网页读取只允许读取当前搜索结果中的候选 URL，按 offset 分页读取 Markdown 文本，再由取证按问题提取证据片段。证据保留 URL、搜索引擎、获取时间以及 `web_snippet` 或 `web_content` 层级，不自动存入项目文献。配置与限制见 [网页搜索说明](../../docs/WEB_SEARCH.md)。

本地候选检索使用论文级 FTS5/BM25，外部候选使用 OpenAlex 文本检索，两路以 RRF 合并。PDF 上传时在 SQLite 按原文版本和页码存储文本，旧版原文在首次取证时按需补建分页文本。无法解析或无可提取文本时使用可用摘要。

对每篇入选论文，取证读取最新有可用文本的版本，覆盖其所有缓存页面。长页按重叠窗口切分，按查询的关键词匹配度每篇取最多 6 个片段，每段最多 1200 字符。单页可有多段，各自保留原文页码和引用 ID。正文片段 ID 根据论文、原文版本、页码和片段偏移构成；网页片段 ID 根据 URL 和字符范围构成。图在累计候选与证据池中按来源身份、定位和内容去重，确保单次运行内引用 ID 唯一，并在后续轮次保留已收集证据。摘要单独标注来源层级，不将其当作全文。正文取证目前依赖 PDF 文本层与关键词匹配，扫描图像、表格布局和跨段语义仍有限制。

数值及单位核验在报告模块执行，结论仍需核对原文。向量检索、模型重排、引用扩展和历史报告版本链尚未实现。

网页读取后的正文候选携带 `content_offset`，取证根据查询选择最多 1200 字符的相关窗口并保留绝对 `char_start`、`char_end`；搜索摘要按 URL 去重。图传给模型的候选正文片段限制为 1600 字符；审查输入最多 12 个候选。工作证据最多 18 条、合计正文最多 21,600 字符；这些上下文限制不改变检索与工具内部返回的候选池。
