# 文献业务

`retrieval.py` 提供项目文献与 OpenAlex 检索、排名合并和收藏夹候选；`evidence.py` 提供论文及网页证据提取。业务函数使用普通参数，不依赖 LangGraph。可调用工具入口见 [src/tools](../tools/README.md)，图状态、规划、补检、综合与核验见 [Agent 工作流](../agents/README.md)。

选择网页范围时，以配置的搜索引擎收集证据，首次检索后最多补检两轮、最多六个去重 URL，每条保留最多 1200 字符。证据包含链接、引擎、获取时间与网页摘要/网页文本/论文摘要层级；不自动存入项目文献。配置与限制见 [网页搜索说明](../../docs/WEB_SEARCH.md)。

检索使用本地 FTS5/BM25 和 OpenAlex 文本检索；两路以 RRF 合并。问答使用 LangGraph 规划、检索、取证、补检和核验；最多使用六篇文献，每篇首个可提取版本检查前 20 页，按问题词选最多三页，每页截取最多 1200 字符并保留页码。摘要单独标注。数值检查仅匹配普通十进制数字及百分号，科学计数法和千分位尚不支持；模型语义核验也不能保证完全正确，需核对原文。向量检索、模型重排、引用扩展和报告修订尚未实现。
