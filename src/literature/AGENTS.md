# 科研流程约定

- `retrieval.py` 负责来源检索、去重与排名合并；`workflow.py` 负责 LangGraph 节点、状态、证据与核验。具体能力和局限见 [README](README.md)，实施状态见 [项目状态](../../docs/STATUS.md)。
- 检索范围始终受项目约束。收藏夹问答仅使用提交时快照与项目文献的交集，不读取其他对话历史，不调用外部检索；空范围返回证据不足。
- 混合来源的外部检索失败时保留本地结果并说明不完整，不吞掉警告或将失败解释为不存在相关论文。
- 原文证据保留文献、文件版本与页码等定位信息；摘要明确标注来源层级，不把摘要当全文或捏造页码。
- 模型输出用数据结构校验；代码检查引用范围、数值与单位依据。模型语义判断不能代替确定性检查；缺失成本数据时不得由准确率推断成本结论。
- 补检最多两轮，无新增证据时停止；修改循环或分支时同时验证终止条件和证据不足路径。
- 模型调用经 `src/integrations/model.py`，正文经 `prompts/` 加载；新增或修改字段同时核对 [提示词规则](../../prompts/AGENTS.md)。

验证检索排名、去重、来源失败、证据定位、范围隔离与核验拒绝路径；选择 [工作流测试](../../tests/AGENTS.md) 和 `scripts/verify_chat.py` 等实际入口，明确模型是否为模拟服务。
