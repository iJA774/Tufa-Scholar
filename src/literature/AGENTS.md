# 文献业务约定

- `retrieval.py` 负责来源检索、去重、排名合并、跨查询候选排序和收藏夹候选；`evidence.py` 负责论文及网页证据提取。通过普通业务参数被工具或工作流调用，不依赖工具注册器、LangGraph 或 `apps/`。
- 检索范围始终受项目约束。收藏夹仅使用提交时快照与项目文献的交集，不调用外部检索；空范围返回空候选和证据。
- 混合来源的外部检索失败时保留本地结果并说明不完整，不吞掉警告或将失败解释为不存在相关论文。
- 原文证据保留文献、文件版本与页码等定位信息；路径、版本和本地正文从项目仓储获取，摘要明确标注来源层级，不把摘要当全文或捏造页码。
- 网页证据保留 URL、搜索服务、获取时间与文本层级，按来源去重，不自动写入论文库。
- 提取的选文、页数和片段限制见 [模块说明](README.md)；调整限制时同步实际行为与说明。模型综合和回答核验属于 [工作流](../agents/AGENTS.md)。

验证检索排名、去重、来源失败、证据定位和范围隔离；入口见 [测试规则](../../tests/AGENTS.md)，跨进程验收见 `scripts/verify_chat.py`。
