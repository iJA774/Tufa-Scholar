# 持久化规则

- SQLite 路径、初始化和升级由存储模块管理；默认路径及相对 `TUFA_DATA_DIR` 的含义不得因模块移动改变。API 和 worker 复用同一仓储。
- 迁移须兼容现有数据库、可重复执行；不得删除或重建用户数据来绕过升级。使用短事务，耗时操作在事务外完成。
- 区分共享文献、项目关联和原文版本；删除关联不得连带删除其他项目仍依赖的数据。研究快照用于重试，执行期间不得被当前收藏夹内容替换。
- 任务结果、消息、报告及成功状态按一致事务提交。研究事件按任务稳定排序和续读，任务删除清理关联事件，重试不复制旧事件流。
- 验证使用临时数据库并检查数据保留和可观察状态；命令见根 README。
