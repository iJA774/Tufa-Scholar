# 工具模块约定

- 工具提供可独立调用的科研能力，不依赖 LangGraph 状态、任务阶段更新或 `apps/`。工作流负责顺序、分支与终止，worker 和仓储负责任务生命周期及报告提交。
- 工具通过显式注册提供名称、说明和 JSON 输入结构，并统一验证调用参数；新增工具同时维护使用说明与可观察行为测试，不用文件扫描或动态导入发现工具。
- 项目、来源与收藏夹快照由调用方构造上下文，不能由工具参数覆盖。工具发现与执行使用相同范围约束；收藏夹只读取快照与项目的交集，禁止外部检索。
- 原文路径和版本从项目仓储获取，不接受调用参数指定的本机路径。证据保留来源层级、版本、页码或网页出处；本地证据正文以项目记录为准。
- `search.py` 适配论文与网页检索，`read_paper.py` 适配证据提取，`read_web_page.py` 提供公网网页分页读取；`registry.py` 负责通用发现与执行。工具保留参数校验和上下文约束，不直接实现文献排名或 PDF 取证算法。
- 工具说明与 docstring 只描述可独立调用的真实参数和返回值；不得混入模型节点 action、候选池 ID 或 LangGraph 流程示例。图层对候选 ID 的映射由工作流自己的 helper catalog 和调用代码负责，并保持 registry 的通用 schema 不变。
- 文献业务复用 [literature/](../literature/AGENTS.md)，外部协议复用 [集成层](../integrations/AGENTS.md)；模型提示词、回答核验和流程补检策略由 [工作流](../agents/AGENTS.md) 管理。

从仓库根目录通过 `tests/test_tools.py` 验证独立调用、参数校验、发现与执行范围，并运行受影响的 API、worker 和科研流程回归，遵守 [测试隔离规则](../../tests/AGENTS.md)。
