# Agent 工作流约定

- `literature.py` 负责 LangGraph 节点、研究状态、模型输入、综合与核验；检索和取证经 [工具入口](../tools/AGENTS.md) 调用，实际业务见 [文献模块](../literature/AGENTS.md)。
- 研究问题、历史、项目和来源范围作为输入传入；Agent 不接收数据库任务行，不查询任务历史，不修改任务状态。阶段变化经可选回调通知运行器，由调用方决定是否持久化。
- 收藏夹问答忽略外部传入的对话历史，不允许一般回答分支绕过取证；输入的项目、来源与论文快照原样传给工具上下文。
- 跨轮候选池与本轮精读集合分开保存，先去重排序再选择最多六篇精读；补检新候选可以替换低排名旧候选，不能在入池前因精读上限截断。
- 补检最多两轮，未获得此前未见的证据时停止；按证据内容与来源判断新增，不能用本轮证据条数是否增加代替。修改循环或分支时同时验证终止条件和证据不足路径。
- 模型输出用数据结构校验；代码检查引用范围、数值与单位依据。模型语义判断不能代替确定性检查，缺失成本数据时不得由准确率推断成本结论。
- 模型调用经 `src/integrations/model.py`，正文从 `src/prompts/` 加载；新增或修改字段同时核对 [提示词规则](../prompts/AGENTS.md)。
- 任务领取和最终结果事务由 worker 与仓储管理，工作流不另建任务执行器或持久化路径。

验证图分支、补检停止、来源及历史隔离和核验拒绝路径；使用 [工作流测试](../../tests/AGENTS.md) 和 `scripts/verify_chat.py` 等实际入口，明确模型是否为模拟服务。
