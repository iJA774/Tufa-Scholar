# 共用 Python 代码约定

## 职责与边界

- `storage.py` 管理数据目录、SQLite 连接、表结构初始化及兼容已有数据库的结构升级。
- `repository.py` 管理项目、文献、任务、消息、报告和收藏夹的持久化与事务边界，供 API 与 worker 复用。
- `settings.py` 管理本地设置与环境变量解析；`logging_setup.py` 管理日志脱敏和轮转。
- 科研业务进入 [literature/](literature/AGENTS.md)，外部服务进入 [integrations/](integrations/AGENTS.md)。共用代码不依赖 `apps/` 的路由或界面，不引入 HTTP 响应类型。

## 存储与状态

- 每个 SQLite 连接启用外键与 WAL。写入使用短事务，联网、模型推理和 PDF 解析放在事务外。
- 结构变更兼容已有用户数据库，初始化可重复执行；不能删除数据库或重建用户数据来绕开升级。
- DOI/arXiv ID 标识文献，文件版本保留原文定位；区分项目关联与全局共享文献。删除关联不得连带删除其他项目依赖的数据。
- 任务输入和收藏夹论文快照用于复现与重试，不在执行时用收藏夹当前成员覆盖快照。
- 科研问答的报告、回答消息、证据与成功状态在同一事务内提交，避免成功任务缺失结果。

## 设置与日志

- 统一解析环境变量优先级，不让 API 与 worker 各自实现不同规则；外部调用应读取用户保存后的有效配置。
- 清除本地密钥不影响环境变量。发现模型时，同来源按环境密钥、草稿密钥、本地密钥顺序解析；清除标记优先于本地及草稿密钥。
- 切换来源不能自动把旧密钥发送给新地址；来源比较包含协议、主机与端口。配置状态与密钥原文分开处理。
- 日志异常只保留安全类型、位置和耗时；新日志路径复用统一格式化与轮转配置。

存储与仓储变更验证数据保留、项目隔离、任务状态和事务可观察结果；设置与日志变更验证优先级、清除与脱敏，入口见 [测试规则](../tests/AGENTS.md)。
