# 运行基础设施约定

- `settings.py` 管理本机设置和环境变量解析，`logging_setup.py` 管理日志脱敏、格式及轮转；不承接科研流程或外部服务协议。
- 统一解析环境变量优先级，API、worker 与外部调用均复用有效配置，不能各自实现不同规则。
- 清除本地密钥不影响环境变量。发现模型时，同来源按环境密钥、草稿密钥、本地密钥顺序解析；清除标记优先于本地及草稿密钥。
- 切换来源不能自动把旧密钥发送给新地址；来源比较包含协议、主机与端口。配置状态与密钥原文分开处理。
- 日志异常只保留安全类型、位置和耗时；新日志路径复用统一格式化与轮转配置，不记录正文、密钥或完整查询 URL。
- 设置存储复用 `src/persistence/`，数据与日志目录继续以有效 `TUFA_DATA_DIR` 为准。

验证设置优先级、清除、来源切换、日志脱敏和轮转，入口见 [测试规则](../../tests/AGENTS.md)。
