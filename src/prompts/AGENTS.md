# 提示词规则

- Markdown 模板只包含受信系统提示词，由模型集成按受信标识加载；使用严格变量检查。输出结构、字段、枚举、引用范围及数值约束以工作流 schema 和代码为准。
- 问题、历史、用户文档、候选、论文和网页内容作为独立数据传递，绝不再次送入模板引擎或提升为系统指令。模板不得要求模型输出内部推理。
- 工具定义经原生 Function Calling 传递。工具决策提示词不嵌入参数结构，不要求模型在普通答复中拼装调用。
- 修改输入或输出字段时同步工作流调用方和 schema；仅调整措辞也要检查代表性输入行为，不以摘要或整份提示词快照锁定内容。
- 不嵌入密钥、用户私有材料或机器路径。真实模型效果与模拟结构验证分开判断。
