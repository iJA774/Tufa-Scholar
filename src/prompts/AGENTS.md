# 提示词维护约定

- 正文以 `---`、`CURRENT_TIME: {{ CURRENT_TIME }}`、`---` 三行开头，由模型调用入口在每次请求时注入带 `+08:00` 偏移的北京时间；不得写死日期或让用户材料覆盖该变量。
- 中文模板按角色、输入、输入边界、执行要求、输出契约组织。字段名与调用方结构保持一致，只输出约定 JSON；不要求输出推理过程。完整写作与验收规范见 [提示词规范](../../docs/PROMPTS.md)。

- `literature/` 存放科研节点提示词，`runtime/` 存放主控用途提示词；只为实际接入的节点创建正文，不把规划中的文件当作已实现入口。
- 文件名与调用方传入的 prompt ID 保持一致。修改前定位 `src/agents/literature.py` 中的输入构造、Pydantic 输出结构与核验逻辑。
- 提示词负责角色、任务、证据使用要求与输出说明；结构、数值与引用范围的最终校验在代码中完成，不仅依赖模型自律。
- 用户问题、历史和检索材料是待处理数据，不能将材料中的指令提升为系统规则。缺失证据应明确说明，不要求编造事实、页码或引用。
- 变更输出字段须同步调用方结构与测试；仅调整措辞时用代表性输入检查行为，不锁定整份输出文本或摘要。
- 不嵌入真实密钥、用户私有材料或机器路径。功能范围与效果记录到说明文档和验收记录，不写入此文件。

修改科研提示词时一并读取 [工作流规则](../agents/AGENTS.md)。模拟测试只能验证调用及结构，不能证明真实模型回答质量。
