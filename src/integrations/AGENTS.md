# 外部集成规则

- 本模块适配外部搜索、论文检索和模型协议，不负责持久化、任务调度或 HTTP 路由。新增兼容行为前核对官方协议及实际调用链；不为未使用的协议新增抽象。
- 所有请求设置超时。凭据通过请求头传递，不写入 URL、错误或日志；切换来源或跟随重定向时不得将凭据带到其他来源。上游错误映射为不含密钥、正文和完整 URL 的安全错误。
- 网页抓取须解析并固定已验证的公网 IP，对每次重定向重新校验；保留 HTTPS 证书与原主机名校验，拒绝内网地址、凭据、非标准端口和超限响应，不加载网页资源。
- 模型发现与调用遵循相同 Base URL 规则：仅为受支持的官方根地址补齐兼容路径，保留自定义路径。模型目录按服务实际返回分页读取，不维护硬编码 ID 清单；失败不得伪装成空列表成功。
- 按调用方契约校验响应并保留学术来源标识和缺失值。模拟 HTTP 用于协议回归，不能代替真实供应商验证；配置读取遵守基础设施规则。
