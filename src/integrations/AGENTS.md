# 外部集成约定

- `openalex.py` 封装 OpenAlex 检索与元数据映射；`model.py` 封装 OpenAI 兼容模型发现与结构化调用。这里处理服务协议，不负责项目持久化、任务调度或 HTTP 路由。
- 增加供应商兼容行为前核对官方协议与现有调用链；保持直接、有限的适配，不为未使用的协议创建后端抽象。返回的模型目录不代表已开通权限或问答兼容性。
- 请求设置超时；凭据放入请求头，不拼入 URL 或日志。上游异常映射成不含密钥、正文和完整 URL 的安全错误。
- 模型发现和调用使用相同 Base URL 规则。仅对明确的官方根地址补齐兼容路径，保留用户自定义路径；不得通过重定向把凭据带到其他来源。
- 模型列表来自服务响应，不维护硬编码模型 ID 清单；有分页时获取完整列表，按实际返回量推进。无列表接口或失败时明确报告，不伪造空列表成功。
- 模型响应按调用方数据结构校验，解析失败明确报错。学术检索保留 DOI、arXiv ID、原文链接、摘要等来源信息及缺失值。

协议变更用模拟 HTTP 响应覆盖路径、请求头、分页、空结果、无效数据、超时与脱敏；真实服务验证单独记录供应商与范围，不能用模拟结果替代。配置读取遵守 [基础设施规则](../infrastructure/AGENTS.md)。
