# API 规则

- FastAPI 路由负责 HTTP 校验、错误映射和文件/报告交付；数据访问、设置、日志与科研工具复用 `src/` 模块。长时间研究任务交给 worker。
- 校验项目、会话和收藏夹的归属；提交任务时固定所需的研究范围快照，重试沿用原范围。删除关联数据不得连带删除共享文献、原文或已提交任务所需数据。
- PDF 提取和其他耗时工作在数据库事务外执行；写事务保持短小。
- 设置及模型发现不得回显密钥，发现使用的草稿凭据不保存，也不转发到切换后的来源。API 日志只记录必要标识和状态，不记录正文、密钥、查询内容或原始异常。
- SSE/轮询只提供所属任务的事件；等待客户端期间不持有数据库事务，客户端断开不能影响 worker。
- 默认绑定回环地址。接口变更按根 README 的命令在隔离 `TUFA_DATA_DIR` 下验证。
