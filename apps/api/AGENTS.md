# API 开发约定

## 职责边界

`main.py` 负责 FastAPI 路由、请求校验、HTTP 错误映射及文件与报告输出。数据访问和任务状态变更复用 [持久化模块](../../src/persistence/AGENTS.md)，设置和日志复用 [基础设施](../../src/infrastructure/AGENTS.md)；搜索能力通过 [工具入口](../../src/tools/AGENTS.md) 调用。长时间科研任务提交给 worker，不在请求中运行完整工作流。修改共用实现时读取 [模块规则](../../src/AGENTS.md)，修改上游调用时读取 [集成规则](../../src/integrations/AGENTS.md)。

## 接口与数据约束

- 检查项目、会话和收藏夹的资源归属，不混入其他项目的数据；不存在或不允许的操作返回明确 HTTP 状态。
- PDF 解析在数据库事务外进行；无可提取文本时保留原文件并返回 `no_extractable_text`。文件摘要用于去重，同一文献的不同文件保留版本。
- 项目内文献由各对话共享，检索候选仅在用户选择保存后进入项目。失败或中断任务重试时创建新任务并保留原记录。
- 设置响应只返回密钥是否配置及来源；校验错误也不得回显含密钥的请求值。配置解析遵守共享代码规则。
- 删除项目时，在短事务内拒绝删除存在运行中任务的项目；保留共享文献和原文。
- 混合来源检索遇外部失败保留本地结果并返回 warnings；单独外部检索失败不得伪装为空结果。收藏夹按项目隔离，加入外部文献时同时保存项目关联；问答提交时固定论文 ID 快照，重试与证据范围沿用快照。
- API 日志写入数据目录 `logs/api.log`；仅记录路由模板、必要资源 ID、状态与耗时，不记录查询字符串、请求正文或原始异常消息。
- 删除收藏夹只移除收藏夹及其关联，保留项目文献、原文、报告和已提交任务快照。
- 问题请求的 `research_mode` 限于 `auto`、`deep`、`quick`，旧请求默认 `auto`；全局 `GET /conversations` 仅平铺会话 `id`、`project_id`、`title` 和最新消息 `updated_at`，不改变会话归属或项目数据。
- 模型发现使用草稿配置，不保存设置，不向新来源自动发送旧密钥；协议适配由集成层处理。

## 验证入口

从仓库根目录运行 `uv run --locked uvicorn apps.api.main:app --host 127.0.0.1 --port 8000`，使用独立 `TUFA_DATA_DIR`。接口变更覆盖成功、非法输入、资源归属和相关副作用，入口见 [测试规则](../../tests/AGENTS.md)；涉及前端代理时另经 `/api` 实际 HTTP 入口验证。
