# Worker 规则

- 保持单进程顺序领取任务；API 与 worker 使用同一 `TUFA_DATA_DIR`。任务调度和持久化由 worker/仓储负责，Agent 只接收准备好的研究输入并通过回调报告阶段或公开活动。
- 历史和来源范围由调用方准备。收藏夹任务使用提交时的论文快照，不读取无关会话历史；重试沿用原任务范围和模式。
- 任务结果、消息、报告和完成状态由仓储一致提交。任务失败需落库并允许后续任务继续；启动时遗留的运行任务标记为中断，不自动重放，重试创建新任务。
- 日志和用户错误只包含安全类型及必要状态，不记录研究材料、密钥或原始异常正文。
- 按 [开发指南](../../docs/DEVELOPMENT.md#验证) 的入口命令验证 worker；使用独立数据目录，不与用户 worker 操作同一数据库。
