# 设置页约定

- 配置状态和输入草稿分开管理，不回显已保存密钥。环境变量来源的地址与模型值只读，界面行为须符合后端优先级。
- `SettingsPanel.tsx` 在工作台上方显示模态卡片，工作台按钮和 `/settings` 复用该入口。模型与思考强度通过共享的 `ModelControls.tsx` 管理。“关于”直接链接到项目 GitHub。
- 服务、网页搜索与本地目录预览均不依赖研究项目。本地目录预览仅显示用户通过浏览器选择的文件相对路径，不读取文件正文、不上传，也不创建项目。
- 只有显式保存才写入配置；切换来源不能继续发送旧地址的草稿密钥。
- 验证环境变量只读、保存回读、跨来源切换与密钥清除。HTTP 验证不等于浏览器交互验证。
- 清理运行日志须单独确认，并在隔离数据目录中验证取消、清理结果和后续日志写入。
