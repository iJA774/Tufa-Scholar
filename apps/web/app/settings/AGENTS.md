# 设置页约定

- 配置状态和输入草稿分开管理，不回显已保存密钥。环境变量来源的地址与模型值只读，界面行为须符合后端优先级。
- 模型发现使用草稿参数，经 `/api/settings/models` 请求；发现不保存设置，只有显式保存才写入。
- 地址或密钥变化后的自动请求需合并频繁输入，并取消或忽略过时响应，避免旧列表覆盖新地址结果。切换来源不能继续发送旧地址的草稿密钥。
- 下拉列表保留已有配置值，支持刷新与手动填写；展示加载、空列表、失败与保存状态，不以请求失败清空用户已选模型。
- 验证列表加载、快速切换地址、失败兜底、环境变量只读、保存回读与密钥清除。HTTP 验证不等于浏览器交互验证。
