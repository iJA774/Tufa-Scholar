# 设置页约定

- 配置状态和输入草稿分开管理，不回显已保存密钥。环境变量来源的地址与模型值只读，界面行为须符合后端优先级。
- `SettingsPanel.tsx` 是工作台与 `/settings` 共用的设置入口，负责通用/外观偏好、服务与模型、网页搜索、本地文件和关于页面；模型与思考强度通过共享的 `ModelControls.tsx` 管理。
- 服务与网页搜索配置不依赖研究空间；本地文件操作必须限定在当前研究空间，缺少范围时通过调用方的 `ensureProject` 按需准备。
- 只有显式保存才写入配置；切换来源不能继续发送旧地址的草稿密钥。
- 验证环境变量只读、保存回读、跨来源切换与密钥清除。HTTP 验证不等于浏览器交互验证。
- 清理运行日志须单独确认，并在隔离数据目录中验证取消、清理结果和后续日志写入。
