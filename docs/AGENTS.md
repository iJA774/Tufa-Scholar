# 文档职责与维护

| 文档 | 职责 |
|---|---|
| `ARCHITECTURE.md` | 设计原则、模块边界、目标工作流与里程碑验收标准 |
| `STATUS.md` | 已实现能力、待实现能力、已知限制与未验证范围 |
| 根目录 `README.md` | 安装、配置、启动、使用入口、实测命令与验收记录 |
| 模块 `README.md` | 模块机制、协议说明、具体使用方式与局限 |
| 各级 `AGENTS.md` | 长期开发约束、职责导航与验证要求，不记录实施进度 |

- 设计目标与已实现行为分开表述；验收记录注明入口、环境、结果和未验证部分，不把计划或模拟结果写成实际能力。
- 能力变化更新 `STATUS.md`，用户操作变化更新 README；普通功能完成不触发 AGENTS 更新。
- 局部规则放在职责最近的目录，在父级导航中按需添加链接。避免重复父级约束，不为单个文件创建没有独立内容的规则目录。
- 相对路径以文档所在目录解析，命令注明工作目录和隔离条件；删除或移动文件时修正引用。
- 纯文档修改检查链接、路径、命令与现有入口的一致性及 `git diff --check`，不声称重新运行了历史测试。
