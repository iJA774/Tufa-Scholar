# 本地文档指南

在“设置 → 本地文档”点击“打开目录”，Windows 资源管理器会打开 `TUFA_DATA_DIR/documents/originals/`，默认是项目下的 `data/documents/originals/`。将原文放入该目录，在“本地文献预处理”中点击“预处理”。同一批次会先在本机将原文转换为 Markdown，随后分类并为当前项目建立索引。

## 支持格式

自动识别并转换 PDF、DOCX 和 TXT。PDF 尝试保留字号标题、双栏阅读顺序和有边框表格，逐页写入 `<!-- page:N -->`；DOCX 保留标题、段落、列表、表格、粗斜体及安全链接，图片用位置标记代替。TXT 自动识别 UTF-8/BOM、UTF-16 和部分常见编码，检测失败时可先将原文件另存为 UTF-8。旧版 DOC 请先另存为 DOCX。扫描 PDF 需要先提取文本，加密 PDF 需要先解密。复杂版式、合并表格、公式和浮动对象仍可能不完整，请核对原文。

## 批次、下载与限制

进度和单文件状态来自服务端，可取消批次、逐个预览与下载，结束后下载保留相对目录结构的 ZIP。同名不同格式采用包含原扩展名的输出名，特殊冲突加稳定哈希。原文件会保留。ZIP 附带转换清单和页码/字符偏移元数据（偏移按下载 Markdown 的 Unicode 字符计数）。预览最多显示 64,000 字符，完整内容通过下载获取。

转换成功的 PDF 自动加入提交时的项目文献库，通过原文哈希关联已有论文和版本。研究员使用预处理后索引的 PDF、DOCX 和 TXT 的 Markdown 结果。已有 PDF 文件与原页证据仍可从历史报告查看。

每批最多 100 个文件、总计 200 MiB。单文件上限为 20 MiB，PDF 最多 200 页，Markdown 输出最多 8 MiB。批次优先处理待转换文件，超出一批时可再次点击转换。最多 4 个未结束批次、1 个 ZIP 打包，独立转换执行器一次运行一个解析子进程，每文件 45 秒、768 MiB 内存上限。关闭设置后转换继续执行，重新打开可读取最近批次。API 关闭或重启会结束遗留转换任务。

## 保存位置与重新转换

设置页生成的 Markdown 保存在 `TUFA_DATA_DIR/documents/conversions/` 下对应的相对目录中，例如 `originals/topic/paper.pdf` 对应 `conversions/topic/paper.pdf.md`。同一相对目录下已有 `paper.pdf.md` 或 `paper.md` 时按已转换跳过。需要重新转换时，可先移走已有的同名 Markdown。

新批次的下载文件和元数据保存在 `documents/conversions/.batches/` 下。临时输入副本在批次结束、取消或恢复时清理。导入文献库的 PDF 快照按内容哈希保存在 `documents/originals/.store/`。历史文献和批次仍可通过原入口读取。

## 分类、索引与清理

预处理也会为已有 Markdown 补做分类和索引。待分类文档发送给已配置的模型服务，模型生成一个或多个研究领域、标签和 20 字以内的内容描述。调用模型前按内容哈希查询 SQLite，已有的分类直接复用。原文和 Markdown 都会保留。

分类失败时，批次会显示具体失败阶段。重新点击“预处理”可使用已有 Markdown 继续分类，无需重新转换。运行日志可按批次 ID 和文件 ID 查询分类结果与错误类型。

“清除已保存的文档”会清空所有项目的本地 Markdown、转换批次及下载文件、预处理分类和全文索引。原始文件、PDF 原文快照、文献库和历史报告保留。确认前请等待转换、分类或下载结束。清除后可从原文重新预处理。

分类默认使用服务的主模型。在“设置 → 通用”填写文档分类模型 ID 可单独覆盖，清空保存可恢复跟随主模型。`TUFA_PREPROCESSER_MODEL` 优先于这一设置。

## 在研究中使用

启用“本地文献”后，研究员先看到当前范围内有哪些研究领域。选定领域后，按页查看文献标题、标签和短描述。正文只在研究员主动调用 Markdown 阅读工具时提供。工具用 SQLite FTS5 选取相关片段，报告记录 Markdown 字符位置。

已有文献和通过本机 API 导入的 PDF 按项目保存，新研究沿用当前项目。PDF 按可提取文本取证并保留版本与页码，图片型或加密 PDF 可能无法取证，重复文件按内容摘要去重。直接上传同样限制单文件 20 MiB、200 页，解析子进程限时 45 秒、内存 768 MiB、提取文本 8 MiB，并发解析一次一个；繁忙时请稍后重试。快照写入中断或损坏后，可重新上传相同文件修复；固定目录保留原文时，再次预处理也可补做项目导入。
