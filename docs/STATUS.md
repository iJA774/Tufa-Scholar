# 项目实施状态

本文件维护能力与验证边界；设计目标见 [ARCHITECTURE.md](ARCHITECTURE.md)，安装与历次实测命令见 [README](../README.md)。以下按仓库实现与已有验收记录整理，不代表本次文档重构重新验证了功能。

## 已实现能力

- Python 模块已按 `agents`、`tools`、`integrations`、`literature`、`persistence` 和 `infrastructure` 分责，提示词位于 `src/prompts/`。工作流、工具适配与文献业务分离；提示词 ID 和默认仓库根目录 `data/` 保持既有语义，布局见 [架构说明](ARCHITECTURE.md)。

- `src/tools/` 提供论文检索、网页搜索与证据提取的统一目录、输入结构和按名称调用入口；API 搜索、worker 检索与 LangGraph 科研节点复用该入口。工具可脱离图单独执行，项目、来源与收藏夹快照由上下文约束，详见 [工具说明](../src/tools/README.md)。

- 网页搜索支持 DeerFlow 1.x 的八种引擎，默认免密钥 DuckDuckGo；设置页配置、独立网页搜索与问答 `web` 范围已接入。引用与证据导出保留 URL、引擎和获取时间，网页内容不自动写入论文库，详见 [WEB_SEARCH.md](WEB_SEARCH.md)。

- 提问页在文献范围旁选择模型与思考强度；供应商档位优先，未声明时提供低、中、高，也可使用供应商默认。选择随任务保存，重试沿用，科研各模型节点使用该任务参数。设置页仅维护服务地址和密钥。

- 五个科研调用节点使用中文结构化提示词；模型请求前在提示词开头注入带时区的北京时间，规范见 [PROMPTS.md](PROMPTS.md)。真实模型的提示词遵循效果待用户验证。

- 项目、会话、文献与收藏夹管理；PDF 导入、相同文件去重和原文版本保存。无可提取文本的 PDF 保留原文件并标记状态。
- SQLite FTS5/BM25 本地检索、OpenAlex 文本检索与 RRF 合并；混合来源外部失败保留本地结果并提示不完整。
- 单 worker 顺序执行任务，支持任务状态、失败与中断处理、显式重试。
- LangGraph 科研问答，包含规划、检索、取证、有限补检、综合与核验，保存报告和证据，支持 Markdown/CSV 导出。跨轮候选池与每轮六篇精读分离，按查询排名融合重新选文。每轮补检按当前子问题定位 PDF 证据，并按累计未见证据判断进展。最终综合仍围绕原始研究问题。
- Agent 通过显式研究输入、历史与可选阶段回调运行，不直接读取任务历史或更新数据库状态；worker 准备历史与范围数据，持久化阶段并提交结果。
- 收藏夹问答在提交时固定成员快照，执行及重试受快照与项目范围约束。
- 本机设置保存、环境变量优先与密钥不回显；OpenAI 兼容模型列表发现、下拉选择、刷新与手动填写，包含百炼分页回退、火山方舟和腾讯 TokenHub 等地址适配。
- Next.js 研究工作台与设置页、本机启动脚本、API/worker 脱敏与轮转日志。
- 前端工作台按项目导航、收藏夹、聊天与会话、搜索、文献及 PDF 导入分责，首页仅保留项目选择和顶层提示；轮询 Hook 在切换作用域或卸载时取消，终态或错误停止调度。结构与验证入口见 [前端说明](../apps/web/README.md)。

## 尚未实现的架构目标

- 模型自主选择工具及动态调用循环；当前科研问答仍由固定 LangGraph 流程编排，工具目录提供独立能力调用与扩展契约。
- 向量检索、模型重排、引用扩展、OCR、完整综述修订与版本链。
- 架构文档中的完整科研流程及对应提示词须按任务逐步实现，不能以目标章节替代实现检查。

## 已知限制与验证边界

- 网页模拟验收的业务断言已通过，但 Windows `taskkill /T` 收尾曾超时，重跑后又因磁盘空间问题中断，尚未确认重跑的子进程全部退出；不能把该次脚本记录为完整通过。详细结果见 [README](../README.md#验证)。

- 新增网页搜索的真实供应商网络可用性、权限、限流与搜索质量尚未实测；仅验证模拟协议和本机流程。没有任意 URL 抓取工具，搜索摘要不代表已阅读完整网页。

- 科研问答的选文、页数、截取与数值格式限制见 [科研模块说明](../src/literature/README.md)；模型核验不能保证事实完全正确，结论仍需原文核对。
- 跨轮选文采用不同查询的检索排名融合启发式，不包含模型语义重排，不能保证真实相关性最优；真实服务选文质量尚未实测。
- 模型发现和科研问答已有本地模拟服务验收；真实云端模型兼容性、权限、输出质量与耗时尚未实测。模型列表不保证每个模型支持本应用所需的对话和 JSON 输出。
- 模型下拉选择已有实际 HTTP 验收，浏览器交互尚未完成验证；其他页面历史浏览器结果见 README，不推定覆盖后续改动。
- OpenAlex 曾有真实联网成功与限流记录，实时可用性和排名会变化；历史结果不代表持续服务保证。
