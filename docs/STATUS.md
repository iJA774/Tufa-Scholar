# 项目状态

本文只记录可用能力、限制和验证边界。设计流程见 [ARCHITECTURE.md](ARCHITECTURE.md)，当前开发任务见 [DEVELOPMENT.md](DEVELOPMENT.md)，安装与最新实测记录见 [README](../README.md)。

## 已实现的基础能力

- 项目、对话、任务、文献、收藏夹、Markdown 报告和 CSV 证据表使用本机 SQLite；worker 单进程顺序执行任务，支持失败、中断和显式重试。
- 本地 FTS5/BM25 检索、OpenAlex 外部论文检索及混合排名；支持 PDF 上传、同文件去重、原文版本和按页保存的文本证据。
- `src/tools/` 提供论文检索、网页搜索、网页读取和证据提取的显式工具目录。工具可独立执行，项目、来源和收藏夹范围由上下文固定。
- 网页搜索支持 DuckDuckGo、Tavily、InfoQuest、Brave、Serper、arXiv、Searx 和 Wikipedia。公开网页与 PDF 读取包含公网地址校验、重定向检查、分页提取和错误脱敏；详见 [WEB_SEARCH.md](WEB_SEARCH.md)。
- 本机设置、环境变量优先、模型发现与模型/思考强度选择；接口和运行日志不回显密钥。前端研究工作台与设置页、单机启动脚本和任务进度轮询已存在。

## 当前工作流能力与限制

工作区可订阅节点与工具活动，并显示模型提供的简短操作目的。支持 SSE 的模型服务可实时预览可公开的生成内容；保存的报告仍由结构、引用和数值校验决定。缺少历史事件的旧任务仍显示原有阶段和轮次小结。

worker 日志按任务 ID、提示词、阶段和尝试次数记录请求字符数，以及供应商返回的输入、输出、总量、缓存与推理 token。字符数用于比较请求体积。供应商未提供字段时显示 `na`，超时请求的实际计费量需在供应商侧核对。

深度研究限制背景搜索、候选预览和工具决策次数，初稿及终稿使用筛选过的证据片段和原引用 ID。上下文估算达到上限后停止工具调用，直接使用已有证据成稿；网页的后续分页也随之停止。连续搜索或读取失败同样可以结束本轮工具循环。终稿没有通过校验的有效引用时，报告明确提示证据不足，并保留可核查的阶段性发现及其引用。上下文预算是本地估算，实际 token 节省和报告质量仍需用供应商数据验证。

背景、规划、工具决策和审查可使用较低的推理强度与完成 token 上限，初稿和终稿保留原有生成空间。显式模型强度设置优先。上游通过 SSE 明确报告完成上限与推理预算冲突时，客户端保留推理强度并重试，后续请求沿用兼容设置。

当前实现流程为 `dispatcher → background_investigator → planner → supervisor`，每轮 supervisor 依次调度 `researcher → analyst → coder → planner`，最多两轮后强制 `reporter` 成稿；简单直接回答由 dispatcher 结束，不调用工具。隔离回归、模拟模型/搜索 HTTP 闭环和实际 API/worker 入口均已通过；节点和数据契约见 [ARCHITECTURE.md](ARCHITECTURE.md) 与 [PROMPTS.md](PROMPTS.md)，实测命令及结果见 [README 验证](../README.md#验证)。

收藏夹研究任务使用提交时的项目内文献快照，不读取其他对话历史，不扩大到收藏夹外来源；空集合应返回证据不足。显式快速探索只直接回答，不读取收藏夹资料。论文和网页来源、候选池及累计证据由代码维持边界。报告引用与数值检查仅对传入证据有效，不能保证模型结论完全正确，仍需核对原文。

## 桌面研究工作区

研究工作区使用跨项目平铺历史，打开历史项时切换到其项目。模型 API 与搜索引擎设置在工作区上方的弹窗中使用，`/settings` 可直接打开同一弹窗。“本地文件”可预览所选目录中的相对文件名，“关于”链接到项目的 GitHub。项目仍限定研究文献范围，PDF 继续通过本机 API 导入。“研究偏好”目前只是占位，不影响请求。

光标悬浮在左上角标志时展开历史抽屉，移出标志和抽屉后自动收起。历史项支持置顶、解除置顶和确认删除。置顶保存在本机数据库；删除会话时保留所属项目及文献，有待处理或正在运行的任务时会拒绝删除。

请求支持 `research_mode=auto|deep|quick`。`auto` 供旧客户端继续使用，且为缺省值；`deep` 由代码强制进入背景研究，`quick` 由代码强制直接回答，不允许 dispatcher 模型反向改变模式。任务持久化通过 additive migration 新增字段，已有任务按 auto 处理；重试复制原模式。

提交深度研究时自动展开 DeerFlow 布局的右侧研究卡片，提供“报告 / 活动”标签。活动复用任务轮询显示真实阶段、小结与来源，报告可用后显示对应回答。桌面使用宽幅双栏与缩放/平移动画；快速探索保留聊天内的状态提示。后端仍提供阶段与小结，不包含 DeerFlow 的逐次工具调用事件流。

后端模式与持久化回归、实际 API/worker 闭环脚本已通过；1280×720 桌面浏览器已覆盖历史、模式、重试、设置、PDF 与报告操作，包括直接访问 `/settings` 后读回本地偏好并返回工作区、外观开关应用及开始页导航。详细入口、结果和模拟边界见根 README 的独立 2026-11-13 验收小节。上一轮开始页验收仍保留在 README 历史记录中，不代替本轮工作区验收。

## 尚未实现或未验证

- 模拟服务不能证明真实云端模型的 JSON 兼容性、权限、响应质量和耗时。真实搜索供应商的当前可用性、权限、限流和结果质量也未由隔离脚本覆盖。
- 前端类型检查、默认 API 代理生产构建已通过；研究卡片已验证 1280×720 和 430×760 视口。5 项轮询回归见上一轮验收记录。
- 本轮浏览器验收使用没有 worker 的 UI fixture；任务模式与 worker 重试由独立实际 API/worker 模拟闭环脚本验证。以上均不代表真实云端模型、真实搜索供应商或真实外部资料质量已验证。
- 没有向量检索、模型语义重排、OCR、引用扩展或历史报告修订版本链。检索排名是词项与来源排序启发式，不保证语义相关性最优。
- 图片型、加密或无法提取文本的 PDF 不能提供按页证据；动态渲染网页可能无法读取。网页搜索摘要和截取片段不等同全文。

隔离单测、模拟 HTTP、实际 API/worker、真实外部服务及浏览器交互分别记录。一个层级通过不代表其他层级已验证；本轮实际命令和未覆盖范围见 [README 验收部分](../README.md#验证)。
