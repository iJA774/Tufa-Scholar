# 项目状态

本文只记录可用能力、限制和验证边界。设计流程见 [ARCHITECTURE.md](ARCHITECTURE.md)，当前开发任务见 [DEVELOPMENT.md](DEVELOPMENT.md)，安装与常用验收入口见 [README](../README.md)。

## 已实现的基础能力

- 项目、对话、任务、文献、收藏夹、Markdown 报告和 CSV 证据表使用本机 SQLite；worker 单进程顺序执行任务，支持失败、中断和显式重试。
- 本地 FTS5/BM25 检索、OpenAlex 外部论文检索及混合排名；支持 PDF 上传、同文件去重、原文版本和按页保存的文本证据。
- `src/tools/` 提供论文检索、网页搜索、网页读取和证据提取的显式工具目录。工具可独立执行，项目、来源和收藏夹范围由上下文固定。
- 网页搜索支持 DuckDuckGo、Tavily、InfoQuest、Brave、Serper、arXiv、Searx 和 Wikipedia。公开网页与 PDF 读取包含公网地址校验、重定向检查、分页提取和错误脱敏；详见 [WEB_SEARCH.md](WEB_SEARCH.md)。
- 提问框支持独立切换“网络搜索”和“本地文献”，按钮亮起时启用相应来源。任务保留提交时的开关状态。
- 本机设置、环境变量优先、手动填写默认模型或提问模型；接口和运行日志不回显密钥。前端研究工作台与设置页、单机启动脚本和任务进度轮询已存在。
- 设置的“本地文档”可在 Windows 资源管理器打开固定原文目录，离线批量转换 PDF、DOCX、TXT，支持进度、取消、预览、单文件及 ZIP 下载。成功转换的 PDF 加入提交时的项目文献库，保留原文哈希和原页定位。DOCX/TXT 支持转换和下载。格式限制见 [README](../README.md#本地文档转换-markdown)。
- “预处理”在同一批次完成 Markdown 转换、独立 `preprocesser` 分类与项目 FTS5 分块索引。分类包含多个研究领域、主题标签和 20 字以内的描述，模型可在通用设置中覆盖。
- “清除已保存的文档”清理所有项目的 Markdown 产物、转换批次、分类关系和 Markdown 索引。原文与 PDF 文献库保留。
- 本地研究先披露领域，再展示选中领域的标题、标签和短描述。researcher 主动选择并读取 Markdown，项目和收藏夹快照约束可见范围，报告引用使用 Markdown 字符区间。

## 当前工作流能力与限制

工作区可订阅节点与工具活动，并显示模型提供的简短操作目的。支持 SSE 的模型服务可实时预览可公开的生成内容。保存终稿前校验 Markdown 格式和显式引用。已核验报告的正文用数字引用，末尾列出参考文献和可用定位，Markdown 下载使用同一格式。缺少历史事件的旧任务仍显示原有阶段和轮次小结。

worker 日志按任务 ID、提示词、阶段和尝试次数记录请求字符数，以及供应商返回的输入、输出、总量、缓存与推理 token。结构化响应的本地修复、重试及工具参数拒绝也可按任务 ID 查询。字符数用于比较请求体积。供应商未提供字段时显示 `na`，超时请求的实际计费量需在供应商侧核对。

深度研究限制背景搜索、候选预览和工具决策次数，初稿及终稿使用筛选过的证据片段和原引用 ID。上下文估算达到上限后停止工具调用，直接使用已有证据成稿；网页的后续分页也随之停止。连续搜索或读取失败同样可以提前收束工具循环。终稿保留无引用的正文，包括明确标注的分析判断。具体工作流额度及本机估算阈值见[架构预算表](ARCHITECTURE.md#工作流预算)；实际 token 节省和报告质量仍需用供应商数据验证。

研究工具决策使用模型服务原生 Function Calling，调用前检查来源、参数和预算。研究计划、审查、初稿和终稿保留模型组织的 Markdown 正文。首轮研究方向决定论文综述或网页调查的写作重点，后续渠道取得的证据仍可用于综合。工作区在任务失败或终稿降级时显示可关闭的顶部通知，列出原因和处理建议。终稿降级后保存通过引用检查的研究草稿或当前证据缺口。未解决缺口以最近一次累计审查为准。

Tavily 的本机代理连接失败可通过一次直连重试恢复。活动记录会区分搜索连接失败与候选网页正文读取被公网校验拦截。

轻量和标准档的背景、规划、工具决策和审查使用较低的默认思考强度。深入档按节点提高默认强度，并复核核心要求、可靠证据和未解决的重要矛盾。API 接受的显式强度优先，设置界面使用自动强度。上游明确报告可选参数不兼容时，客户端按拒绝信息调整请求并重试。

科研问答支持直接回答和深度研究。工作流节点、收束条件和数据契约见 [架构文档](ARCHITECTURE.md#科研工作流)与 [提示词说明](PROMPTS.md)。

收藏夹研究任务使用提交时的项目内文献快照，不读取其他对话历史，不扩大到收藏夹外来源；空集合应返回证据不足。显式快速探索只直接回答，不读取收藏夹资料。论文和网页来源、候选池及累计证据由代码维持边界。终稿的引用只验证证据能否追溯到范围内的材料，模型结论仍需核对原文。

## 桌面研究工作区

研究工作区使用跨项目平铺历史，打开历史项时切换到其项目。模型 API 与搜索引擎设置在工作区上方的弹窗中使用，`/settings` 可直接打开同一弹窗。弹窗打开和关闭时淡入淡出，设置分类与研究面板的页签选框会滑到当前项。“本地文档”提供打开原文目录和离线转换入口，“关于”链接到项目的 GitHub。项目仍限定研究文献范围。

“研究偏好”中的深度、原始证据优先和相关性过滤随新提问生效，重试沿用任务快照。报告格式可在界面选择学术综述或探索发现，现阶段不改变终稿。

光标悬浮在左上角标志时展开历史抽屉，移出标志和抽屉后自动收起。历史项支持置顶、解除置顶和确认删除。置顶保存在本机数据库；删除会话时保留所属项目及文献，有待处理或正在运行的任务时会拒绝删除。

打开历史会话后可在原问题下方点击“重新回答”，适用于已完成、报告降级、失败和中断任务。重新回答使用当前模型设置，保留原研究范围与偏好；旧回答和报告继续保留，不重复插入原问题。活动任务结束前无法再次提交，同一入口支持重复生成。

打开会话后，“设置”下方显示已记录的会话 Token。重新回答和重试沿用会话累计值。历史会话在收到首笔可统计用量前显示“暂无记录”。PowerShell 启动器在首页、研究工作区和 API 代理就绪后打开默认浏览器。

提问框的模式菜单提供“自动”“深度研究”和“快速探索”。`auto` 是工作区及 API 的默认值，由 dispatcher 分流。`deep` 由代码强制进入背景研究，`quick` 由代码强制直接回答。重试沿用任务已保存的模式。

提交深度研究时自动展开 DeerFlow 布局的右侧研究卡片，提供“报告 / 活动”标签。活动显示节点阶段、工具调用及模型公开内容预览。进行中的活动有动态图标和标题扫光，完成或失败时显示对勾或警告图标，并自动收起详情，可通过右侧箭头重新展开。报告可用后显示对应回答。桌面使用宽幅双栏与缩放/平移动画；快速探索保留聊天内的状态提示。
## 尚未实现或未验证

- 模拟服务不能证明真实云端模型的 JSON 兼容性、权限、响应质量和耗时。真实搜索供应商的当前可用性、权限、限流和结果质量也未由隔离脚本覆盖。
- 没有向量检索、模型语义重排、OCR、引用扩展或历史报告修订版本链。检索排名是词项与来源排序启发式，不保证语义相关性最优。
- 图片型、加密或无法提取文本的 PDF 不能提供按页证据；动态渲染网页可能无法读取。网页搜索摘要和截取片段不等同全文。

验证命令及适用范围见 [README](../README.md#验证)。

## Benchmark 评测

评测工作台与 CLI 支持锁定的 DRB v1 题库、版本校验、语言与领域筛选、随机抽样和指定题目。批次复用真实科研工作流，隔离项目、会话和配置。支持仅生成、完整评测和仅评分，阶段间可暂停、继续、跳过、停止和重试。Worker 异常重启后恢复已授权的批次进度。

工作台提供 RACE 与 FACT 评分、覆盖率、运行统计、分组比较和单项明细。导出支持 JSONL、JSON、CSV、Markdown 和 ZIP。费用及 Token 的可用范围取决于供应商响应。官方 Judge、Reader 和大规模真实科研评测需要用户配置和授权后验证。用法与范围见 [Benchmark 使用说明](BENCHMARK.md)。
